Solar Cycle Classroom Explorer

Interactive plots for studying long-term solar and geomagnetic activity. Drag panel handles to reorder; choose Half width on two panels to compare them side by side.

International Sunspot Number

Monthly mean total sunspot number and the 13-month smoothed series. Use the toolbar to zoom, pan, autoscale, inspect values and export an image.

Source: NOAA/SWPC ISES solar-cycle data

Number of Spotless Days per Year

A spotless day is a day for which the daily total sunspot number is zero.

Source: WDC-SILSO, Royal Observatory of Belgium

Butterfly Diagram

Latitude of reported sunspot regions versus time, showing the equatorward migration of active regions through each solar cycle.

Butterfly data have not been built yet. Run python build_data.py once, then reload this page.
Source: NOAA/NCEI Solar Region Summaries

10.7 cm Solar Radio Flux (F10.7)

Observed monthly F10.7 solar radio flux and its smoothed progression. F10.7 measures solar radio flux at 10.7 cm (2800 MHz) and is commonly used as a proxy for solar EUV activity.

Sources: NOAA/PSL monthly flux (1995–2004); NOAA/SWPC ISES solar-cycle data

Number of C-, M- and X-class Solar Flares per Year

Annual GOES soft X-ray flare counts. Select an individual flare class or display all classes as a stacked bar chart.

Flare-count data have not been built yet. Run python build_data.py once, then reload this page.
Source: NOAA/NCEI SWPC Solar Event Reports

Individual GOES Flare Peak X-ray Flux

Peak 0.1–0.8 nm X-ray irradiance for each C-, M- or X-class flare, shown on a logarithmic scale. Each point is one flare; the axis begins in 1995 for comparison with the annual counts above.

GOES flare peaks could not be loaded. Run python build_data.py --flares-only to create the local data file, then reload this page.
Source: NOAA/NCEI GOES XRS science-quality flare report

Geomagnetic Storm Days per Year

Each day is classified by the strongest 3-hour Kp interval that day. Select individual NOAA G levels or display all levels as a stacked bar chart.

Source: GFZ German Research Centre for Geosciences, Kp index
